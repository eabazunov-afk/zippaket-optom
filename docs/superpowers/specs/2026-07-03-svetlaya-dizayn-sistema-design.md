# Светлая дизайн-система витрины (A3 «Бронза / тихая роскошь») — Design Spec

## Проблема и контекст

Витрина zippaket-optom.ru сейчас на тёмной теме, а в коде **три конкурирующие системы токенов**: `--z-*` (тёмная, ~379 использований, `css/site-premium.css`), `--pm-*` (`css/premium.css`, 51) и легаси `--primary/…` (`css/style.css` 78 КБ, 79). Плюс ~390 «сырых» hex-цветов вне токенов и смешанные иконки (FontAwesome + Phosphor). Владелец решил: витрина переходит на **светлую тему с айдентикой** (тёмная хуже для читаемости прайса/спеков, фото прозрачного пластика, ожиданий B2B; прод и так светлый — см. фазы A/B/C).

**Ключевой рычаг:** Фазы A/B/C построены на токенах `--z-*`. Значит редизайн — это **ремап значений `--z-*` (тёмная→светлая)**, а не переписывание разметки. Разметка, использующая `var(--z-*)`, перекрашивается автоматически.

## Направление: A3 «Бронза / тихая роскошь»

Утверждено визуально (макеты в браузере-компаньоне). Тёплая нейтральная бумага вместо стерильно-белого; почти монохром; **один бронзово-золотой акцент**; редакционная антиква **Fraunces** в **компактном** масштабе + чистый гротеск **Plus Jakarta Sans** для данных. Премиально и «с характером», но цифры/спеки читаются мгновенно. Тёмные «акцент-моменты» (полосы доверия, финальный CTA-бэнд, футер) сохраняем как ink-панели на светлом — дают ритм и премиум.

**CTA-градиент:** `linear-gradient(180deg, var(--z-gold) → var(--z-gold-2))`, текст `#231A08` (тёмный на бронзе — контраст ОК).

## Типографика (компактный масштаб)

- **Display (Fraunces, 600):** H1 hero `clamp(30px, 4vw, 38px)`, курсив для акцентного фрагмента (`em`, цвет `--z-mint`); H2 секций `24px`; заголовок карточки `16–17px`; крупные цифры доверия `20–22px`. `letter-spacing:-.015em`, `line-height:1.1`.
- **Body (Plus Jakarta Sans):** основной `15px`, подзаголовок/подпись `13–14px`, `line-height:1.5`.
- **Eyebrow:** `11px`, `letter-spacing:.14em`, `uppercase`, цвет `--z-mint`.
- **Цены/остатки:** `font-variant-numeric: tabular-nums`, `600`.
- Fraunces подключается в `header.php` вместо Space Grotesk (с `display=swap`).

## Компоненты (язык)

- **Кнопки:** CTA — бронзовый градиент + тёмный текст + мягкая тень; secondary «ink» — тёмная плашка/белый текст (напр. «Найти»); ghost — прозрачная с `--z-hairline-strong`, ховер → бронза. Скругление `9–12px`.
- **Карточка товара:** белая, тонкий хайрлайн (не тяжёлая тень), фото на светлой подложке. Блок цен — рамка + строки, опт-строка (main) на `--z-surface-2` тинте с бронзовой ценой. Полоса остатка — бронзовый `--z-mint`. Кнопки: CTA «Быстрый заказ» + ghost «КП».
- **Hero:** eyebrow + Fraunces-заголовок + подзаголовок + поисковая строка (белая, хайрлайн, ink-кнопка «Найти») + 2 CTA + чипы доверия с бронзовой точкой; визуал-фото со скруглением + плавающая карточка-факт.
- **Тёмные акцент-панели:** полоса доверия / финальный CTA-бэнд / футер — ink-фон `--z-ink`, текст `--z-on-ink`, цифры-акцент `--z-on-ink-acc` (светлый бронз).
- **Секции:** eyebrow (бронза) + Fraunces H2; сетки на существующих `.z-*` классах.
- **FAB / формы / select:** на токенах; стилизовать `.z-form select` централизованно (закрывает стиль-долг Фазы B).

## Иконки

Единая система — **Phosphor** (уже в новых компонентах A/B/C, чище). FontAwesome вывести из редизайненных публичных поверхностей; временно оставить только там, где глубоко вшит (калькулятор) — до отдельной чистки. Не тянуть новых иконочных зависимостей.

## Логотип

Перекрашен под A3 (форма 1:1 с исходным SVG). Вариант «тёмный бейдж + бронза»: плашка `#1A1712`, подложка/«язычок» `#C6A24E`, буквы `#FBFAF6`. Готовый ассет: `docs/superpowers/specs/assets/2026-07-03-logo_zip_optom_bronze.svg` → при реализации заменит `www/images/logo_zip_optom.svg`. Для тёмного футера — при необходимости вариант с плашкой `#2A2620` (или логотип на светлой врезке внутри футера).

## Консолидация трёх систем токенов → одна

1. **Канон** — `--z-*` в `:root` (`site-premium.css`), ремапнутые в светлые A3-значения (таблица выше). Это единственная система цветов витрины.
2. **`--pm-*` (`premium.css`)** — вывести: сопоставить использования с `--z-*`, затем удалить дубли. `premium.css` либо сводится к тонкому набору, либо растворяется в `site-premium.css`.
3. **Легаси `style.css` (78 КБ, `--primary`/hex)** — рискованно удалять целиком (шапка/футер/калькулятор/cookie/модалки). Стратегия: (а) нейтрализовать цвета — привязать к `--z-*` или переопределить; (б) выпилить мёртвые правила, безопасные к удалению; (в) остальное — постепенно. Полная зачистка — отдельная задача, не блокирует запуск светлой темы.
4. **~390 «сырых» hex** — в затрагиваемых публичных файлах заменять на токены; hex в `catalog.css`/`style.css` ремапить к светлой палитре. Гейт: новые правки — только через `var(--z-*)`, ноль новых сырых hex (правило Фаз A/B/C сохраняется).

## Область применения

**Site-wide публичные страницы:** главная, каталог, карточка товара, корзина, checkout, статические/юр-страницы, формы (`review_add`, лид-формы, `price.php`), `zip_lock_logo`, 404. **Тёмная тема публичной витрины ретайрится полностью.**

**Вне области:** админка (`admin/*`) — у неё свой светлый концепт, отдельная выверка позже. WebP/реальные фото товаров (asset-задача). Новые фичи/страницы. Полная физическая зачистка `style.css`.

## Доступность

- Бронза `#9A7B2E` на белом — контраст ~3.5–4:1 (пограничен для текста). Для **текст-ссылок и мелкого текста** использовать `--z-mint-2 #7C6122` (≈5:1, AA). Бронза как фон-акцент/иконки/крупные элементы — ок.
- CTA: тёмный текст `#231A08` на бронзовом градиенте — контраст AA.
- Основной текст `#1A1712` на бумаге `#F4F2EC` — высокий контраст.
- Сохранить `data-reveal` доступность: `prefers-reduced-motion` → `opacity:1` (уже есть).

## Критерии приёмки

- Публичная витрина рендерится в светлой A3 на **всех** страницах из «Области применения»; тёмных остатков нет.
- **Одна** система токенов (`--z-*`) управляет цветом; `--pm-*` и легаси-цвета сведены/нейтрализованы; в затронутых файлах нет новых сырых hex.
- Типографика: Fraunces (компактно) + Plus Jakarta Sans; цены tabular-nums.
- Иконки — Phosphor на редизайненных поверхностях.
- Логотип заменён на бронзовый SVG; работает на светлой шапке и тёмном футере.
- Контраст текста — AA (текст-ссылки на `--z-mint-2`).
- PHPUnit зелёный (дизайн-изменения не ломают логику/тесты); ключевые страницы 200; визуальная регрессия проверена скриншотами.

## Non-goals

WebP/реальные фото и галерея; рескин админки; новые фичи; полная физическая зачистка `style.css` (только нейтрализация цветов + безопасный трим); мультиязычность/новые страницы.
