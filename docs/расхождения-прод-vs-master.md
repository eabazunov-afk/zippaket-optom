## A. Фичи прода, которых нет в тёмном master (перенести)

- [x] **A1. Поиск/фильтр ZIP-пакетов на главной** — на проде hero это подбор по
  размеру / толщине / типу замка (H1 «Найдите ZIP-пакеты…»). В тёмной версии
  hero — статичный лендинг. Решить: добавить фильтр на главную тёмной версии.
  **Сделано** (фаза A): форма `.z-hero-search` в hero — `www/index.php:215`,
  GET на `/katalog_zip_paketov/` с полями поиска/типа/толщины.
- [x] **A2. Секция «Хиты продаж»** — витрина карточек товаров прямо на главной
  (на проде 8 позиций). В тёмной есть блок распродажи из БД — свести к формату «хиты».
  **Сделано**: `www/index.php:269` (`<h2>Хиты продаж</h2>`), данные —
  `Catalog::getPopularProducts()` (`www/includes/catalog_functions.php:284`)
  + `home_pick_hits()` (`www/includes/home_view.php`).
- [x] **A3. Секция «Новинки»** — отдельный блок (на проде 4 позиции). В тёмной нет.

- [ ] **A4. Категории Stand-Up и Вакуумные пакеты** — прод их рекламирует в футере;
  в нашей БД/каталоге только слайдеры и грипперы. Решить: заводить ли эти категории
  (товары + фото + цены) или убрать из наполнения как неактуальные.
